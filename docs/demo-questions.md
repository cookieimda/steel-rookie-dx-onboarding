# 시연 질문 목록 (AI 튜터 · 평가 시험)

시연 진행자가 보고 그대로 입력하는 질문 모음이다. 질문은 새로 지어내지 않았다. 아래 셋에서 골랐다.
- 학습 평가 세트(`llm/eval/learning/*.jsonl`, 2026-10-06 Gemini 51/51 통과 세트 포함)
- 추천 질문 칩(`frontend/3d-demo/learning-suggestions.js`)
- 제선 루브릭 질문 은행(`content/rubrics/final/01_제선.json`)

질문을 바꾸거나 더하면 `npm run eval:learning`으로 근거 있는 답이 나오는지 먼저 확인한다.

## 준비

| 항목 | 값 |
|---|---|
| 서버 | `npm run start:gemini` (시연은 Gemini. 로컬 Ollama는 답 하나에 30~60초라 시연에 쓰지 않음) |
| 시연 계정 | `trainee02` / `steel-2026-demo`. #178 병합 뒤 `npm run db:seed-demo`를 다시 돌리면 네 공정에 재도전·다시 볼 개념·재도전 필요·오개념이 고르게 들어간다. 시연 기록(seed)은 시험 응시를 막지 않으므로 trainee02로도 제선 시험을 볼 수 있다 |
| 개발용 계정 | `trainee01` (시연 기록 없음. 처음부터 보여 줄 때) |
| 관리자 | `admin01` |
| 지연 | Gemini flash-lite는 혼잡하면 호출당 15~33초. 평가 시험 한 단계가 30~60초 걸릴 수 있으니 기다리는 동안 설명할 말을 준비한다 |

시연 기록을 처음 상태로 되돌리려면 `npm run db:seed-demo`를 실행한다. 시연 기록(seed)만 다시 만들고 실제 기록은 그대로 둔다.

## 추천 흐름 (약 7분)

1. **로그인**: `trainee02`로 로그인한다. 학습 기록에서 공정별 이해도, 다시 볼 개념, 오개념을 보여 준다.
2. **3D 제선 + 튜터** (아래 A). 질문 3~4개를 한다. 설비 하이라이트, 작동 보기, 근거 토글이 보인다.
3. **오개념 단정** (아래 B). "코크스는 불순물 없애려고 넣는 거죠?"라고 묻는다. 튜터가 바로잡고, '보충학습 · 개념' 칩이 생긴다.
4. **보충학습**: 칩을 누르고 확인 문제에 답한다(아래 C).
5. **평가 시험** (`/exam`, 아래 D). 제선 시험을 시작해 일부러 부분 정답을 한 번 낸다. 설명과 재확인 질문이 이어진다.
6. **결과**: 이해도 게이지와 개념별 막대를 보여 주고, 학습 기록의 '다시 볼 개념'으로 돌아간다.
7. **관리자**: `admin01`로 신입사원별 진도와 오개념 개수를 보여 준다.

## A. 학습 튜터 질문

`화면`은 질문할 때 3D에서 골라 둘 설비다. 비어 있으면 공정 전체 화면에서 묻는다.

### 제선 (근거 자료가 가장 많음, 시연 1순위)

| 질문 | 화면 | 보여 줄 기능 |
|---|---|---|
| 제선 공정 순서를 보여 줘 | | 공정 흐름 애니메이션(play_animation) |
| 고로는 무슨 일을 해? | | 고로로 카메라 이동 + 하이라이트 |
| 고로는 어떻게 작동해? | | **설비 작동 보기**(단계별 3D) |
| 이 설비는 뭐 하는 거야? | 고로 | 지시어 질문: 보고 있는 설비에 그대로 머묾 |
| 이 설비가 바람을 데우는 과정을 보여 줘 | 열풍로 | 열풍로 작동 보기 |
| 여기 담긴 쇳물은 몇 도야? | 토페도카 | 수치를 근거와 함께(약 1,500℃) |
| 쇳물은 다음에 어느 공정으로 가? | | 다른 공정(제강)으로 화면 이동 |
| 고로는 그렇게 뜨거운데 왜 안 녹아? | | 근거 토글 "근거 N개" → 출처 기사 열기 |
| 가루 철광석을 고로에 바로 넣으면 안 돼? | 소결기 | 가루 원료가 고로를 막아 가스 흐름을 방해한다는 근거로 소결의 필요성 설명 |
| 고로 슬래그는 버려? | 출선구 | 시멘트·도로 골재로 재활용 |
| FINEX도 소결광을 써? | | 고로와 FINEX 구분 |

**추천 칩**은 설비를 고르면 바뀐다. 칩을 눌러도 같은 효과가 난다. 칩 답은 한 번 받으면 저장해 두므로, 시연 전에 칩을 한 번씩 눌러 두면 당일에 바로 나온다(start:gemini는 미리 받기를 끔).
- 소결기: "소결광은 왜 만들어?"
- 열풍로: "열풍은 몇 도야?"
- 토페도카: "토페도카는 왜 어뢰차라고 불러?"

### 제강

| 질문 | 화면 | 보여 줄 기능 |
|---|---|---|
| 제강 공정 순서를 보여 줘 | | 공정 흐름 |
| 전로는 무슨 일을 해? | | 전로 하이라이트 |
| 이 설비 안은 몇 도까지 올라가? | 전로 | 지시어 + 수치(약 1,700℃) |
| 왜 공기 말고 순산소를 불어 넣어? | | 근거 설명 |
| 용강은 다음에 어느 공정으로 가? | | 연주로 화면 이동 |

### 연주

| 질문 | 화면 | 보여 줄 기능 |
|---|---|---|
| 연주 공정 순서를 보여 줘 | | 공정 흐름 |
| 턴디시는 무슨 역할을 해? | | 턴디시 하이라이트 |
| 주형을 빠져나올 때 슬래브 속은 다 굳어 있어? | 주형 | 아니라고 바로잡고, 겉 껍질(응고 셸)만 굳어 나온다고 설명 |
| 슬래브, 블룸, 빌릿은 뭐가 달라? | | 제품 구분 |

### 열간압연

| 질문 | 화면 | 보여 줄 기능 |
|---|---|---|
| 압연 공정 순서를 보여 줘 | | 공정 흐름 |
| 재가열로는 왜 슬래브를 다시 데워? | | 재가열로 하이라이트 |
| 여기서 감는 온도가 왜 중요해? | 권취기 | 지시어 질문 |
| 열연이랑 냉연은 뭐가 달라? | | 개념 구분 |

### 일부러 보여 줄 '거절·안내' 질문

| 질문 | 기대 동작 |
|---|---|
| 고로 밸브는 어떻게 열어요? | **안전 질문**: 모델을 부르지 않고 "현장 작업표준·담당자 확인" 안내 |
| 비상 정지 버튼은 어디서 눌러요? | 같은 안전 안내 |
| 고로 하나 짓는 데 돈이 얼마나 들어? | **자료에 없는 질문**: 지어내지 않고 "공개 자료로 확인하지 못했다"고 답함 |

## B. 오개념 단정 → 학습 메모 → 보충학습

오개념 메모와 보충학습은 **루브릭이 있는 제선 개념만** 생긴다. 다른 공정의 오개념 질문에는 튜터가 바로잡기만 하고 메모는 남기지 않는다.

| 질문 | 화면 | 기대 동작 |
|---|---|---|
| 코크스는 불순물 없애려고 넣는 거죠? | | "불순물 제거는 주된 역할이 아니다"로 바로잡고 CO 환원을 설명. 메모(코크스의 역할)가 남고 '보충학습' 칩이 생김 |
| 소결은 쇳물 만드는 과정이잖아요. | 소결기 | "소결은 전처리"로 바로잡음. 메모(소결의 목적) |
| 고로에서 바로 용강이 나오는 거죠? | 고로 | 용선 → 제강 전로 → 용강으로 바로잡음 |
| 전로에서 철광석을 녹여서 쇳물을 처음 만드는 거죠? | | (제강) 바로잡기만 하고 메모는 없음 |
| 열간압연은 강판을 차갑게 식힌 다음 눌러 펴는 거죠? | | (압연) 바로잡기만 함 |

대조용: "고로에서 철광석의 산소를 떼어내는 게 맞나요?"는 맞는 내용이라 **메모가 남지 않는다**.

## C. 보충학습 확인 문제 답

칩을 누르면 근거 검색 → 설비 3D → 설명 → 확인 문제 순서로 진행된다. 확인 문제의 문장은 매번 다르니, 아래처럼 핵심만 담아 답한다.

| 개념 | 맞는 답 (해결) | 틀린 답 (다른 각도로 한 번 더) |
|---|---|---|
| 코크스의 역할 | 코크스가 열풍과 반응해 일산화탄소를 만들고, 그게 철광석의 산소를 떼어내요. | 코크스는 쇳물의 불순물을 없애요. |
| 소결의 목적 | 철광석을 고로에 넣기 좋은 소결광으로 만드는 전처리예요. | 소결에서 쇳물을 만들어요. |

## D. 평가 시험 (`/exam`, 제선 3개 개념)

시험은 제선만 열려 있다. 제강·연주·열간압연은 '준비 중'으로 보인다.
1. "준비됐나요?"에는 아무 말이나 답하면 시작한다(예: "네, 준비됐어요").
2. 질문 문장은 아래 질문 은행에서 골라 말투만 다듬어 나온다.
3. 부분·틀림·힌트 요청이면 놓친 부분부터 설명하고 **다른 각도로 한 번만** 다시 묻는다.

### 소결의 목적
- 질문 예: "소결 공정은 어떤 원료를 무엇으로 바꾸고, 그렇게 바꾼 것은 다음에 어느 설비에서 쓰이나요?"
- **맞음:** 소결은 가루 철광석을 고로에 넣기 좋은 소결광으로 만드는 전처리 공정이에요. 만든 소결광은 고로에 들어가요.
- 부분: 철광석을 가공하는 과정이에요.
- 틀림: 철광석을 녹여서 쇳물을 만드는 과정이에요.

### 고로에서 코크스의 역할
- 질문 예: "고로 안에서 코크스는 무엇을 만나 어떤 물질을 만들고, 그 물질은 원료에 어떤 화학적 작용을 하나요?"
- **맞음:** 코크스가 열풍과 반응해 일산화탄소를 만들고, 그 일산화탄소가 철광석에서 산소를 떼어내는 환원을 일으켜요.
- 부분: 코크스는 연료라서 열을 내요.
- 틀림: 코크스는 용선의 불순물을 없애요.

### 고로에서 용선이 만들어지는 과정
- 질문 예: "고로 안에서 원료가 어떤 두 가지 변화를 거쳐 용선이 되는지, 그리고 그 용선은 다음에 어느 공정의 어떤 설비로 가서 무엇이 되는지 설명해 주세요."
- **맞음:** 고로에서 철광석이 환원되고 녹아서(용융) 용선이 되고, 용선은 제강 공정의 전로로 가서 용강이 돼요.
- 부분: 고로에서 쇳물이 만들어져요.
- 틀림: 고로에서 바로 강판이 나와요.

### 시연 시나리오 (통과, 약 83%)
| 순서 | 입력 | 결과 |
|---|---|---|
| 준비 | 네, 준비됐어요. | 첫 질문 |
| 소결 | (맞음) | 바로 1점 |
| 코크스 | (부분) 코크스는 연료라서 열을 내요. | 설명 → 재확인 질문 |
| 코크스 재확인 | (맞음) | 1점 |
| 용선 | 잘 모르겠어요, 힌트 주세요. | **힌트 요청(assisted)** → 설명 → 재확인 |
| 용선 재확인 | (부분) 고로에서 쇳물이 만들어져요. | 0.5점 → 이해도 83% 통과, '다시 볼 개념'과 복습 일정에 남음 |

통과하면 이 시험은 다시 볼 수 없다(409). 다시 시연하려면 `trainee01`을 쓰거나 `npm run db:reset-user -- trainee01 --origin live --yes`로 기록을 지운다. 실제 기록이므로 필요하면 `eval:export-human`으로 먼저 백업한다.
