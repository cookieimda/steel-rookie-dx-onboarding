# 학습 페이지 비스듬한 모서리(Diagonal) UI

화면마다 모양이 달라(둥근 카드, 알약 버튼, 공정 화면만 비스듬한 모서리) 하나의 시각 언어로 맞춘다. 이번에는 **학습 페이지만** 바꾸고, 규칙은 공용 스타일 파일로 만들어 다음 화면(평가 시험·홈·공정 화면)에서 다시 쓴다.

- 대상 화면: `/login` → `My Page.dc.html`(껍데기) → `frontend/login_ui/Trainee Dashboard.dc.html`(신입사원 학습 페이지, "LEARN & ASK.")
- 참고: 공정 화면 `frontend/3d-demo/steel-index.html`의 HUD 스킨(`clip-path`로 모서리를 자름), GravixPoint 시안(미색·주황·검정, 각진 대문자 글꼴, 두 모서리를 자른 카드)
- 결정(2026-10-15): 범위는 학습 페이지만, 색은 참고 시안처럼(라이트·다크 둘 다), 정보 순서는 학습 먼저·기록은 아래, 구현은 공용 스타일 파일

## 1. 시각 언어 — `frontend/login_ui/diagonal.css`

서버(`backend/src/app.ts`)는 `/3d-demo`(`frontend/3d-demo`)와 `/login_ui`(`frontend/login_ui`)만 내려준다. 새 폴더(`frontend/shared/`)를 쓰려면 공용 파일 `app.ts`를 고쳐야 하므로, 공용 스타일은 `login_ui`에 둔다. 공정 화면 등 `/3d-demo/` 페이지는 `../login_ui/diagonal.css`로 같은 파일을 쓴다.

### 모서리
- 처음에는 `clip-path`로 왼쪽 위·오른쪽 아래를 비스듬히 잘랐으나, **둥근 모서리로 바꿨다**(2026-10-15 요청). 클래스 이름 `.dg-cut`은 그대로 두고 `--c`만큼 `border-radius`로 둥글린다.
- 둥글리는 크기는 변수로 정한다: 큰 패널 `--cut-l: 20px`, 카드 `--cut: 14px`, 버튼·탭·칩 `--cut-s: 10px`. 배지·알림·태그는 6px.
- 선이 필요한 패널은 바깥 요소에 선 색 배경을 깔고 안쪽 층(`::before`)을 1px 작게(반지름도 1px 작게) 덮는 방식을 유지한다.

### 색
| 역할 | 라이트(기본) | 다크 |
|---|---|---|
| 바탕 | `#f3f2ee` | `#141416` |
| 글자 | `#141414` | `#f2f2f2` |
| 어두운 패널 | `#1c1c1e` | `#202024` |
| 주황 포인트 | `#ff9e64` | `#ff9e64` |
| 선 | `rgba(0,0,0,.14)` | `rgba(255,255,255,.13)` |

- 주황 `#ff9e64`는 공정 화면 HUD의 활성 버튼 색(`steel-index.html` `--hot`)과 같은 값이다. 채도가 높던 `#ff6b35`에서 바꿨다(2026-10-15 요청). 라이트 테마의 주황 글자는 `#c25a1c`.
- 주황은 숫자 카드, 지금 고른 탭, 주요 버튼에만 쓴다.
- 테마는 지금처럼 `body[data-theme]`와 저장값 `st-rookie-theme`를 따른다.

### 글꼴
- UI 글꼴: Montserrat(Google Fonts, 400~800). 한글은 Pretendard로 이어진다(`--font-ko`, `--font-en` 모두 `"Montserrat", "Pretendard", ...`). 2026-10-15 Chakra Petch에서 바꿨다.
- 작은 라벨도 Montserrat 대문자, 넓은 자간. JetBrains Mono는 도면 번호처럼 고정폭이 필요한 곳에만 쓴다.

### 선과 격자
- 구역 사이를 1px 선으로 나누고, 구역 모서리에 `+` 표시를 둔다(도면 느낌).

## 2. 화면 순서

1. **헤더**(위에 붙음, 오른쪽 아래 모서리가 둥근 패널): 로고 · `TRAINEE` · 데이터 출처 배지 / 테마 · 로그아웃 · **3D 공정 화면**(주황, 지금 이름은 '학습 화면'이라 학습 페이지와 헷갈려서 바꾼다) · 평가 시험
2. **짧은 제목띠**: 왼쪽 `[ TRAINEE ]` · LEARN & ASK.(최대 48px) · 이름·사번 / 오른쪽 주황 패널에 **지금 공정 상태**(예: `02 제강 · 이해도 72% · 통과 전`, 공정별 데이터 `secCards`를 쓴다)
3. **학습 영역**: 왼쪽 2D 학습 모듈 / 설계도·필기 탭(비스듬한 칸 탭), 오른쪽 AI 튜터(어두운 패널, 포석호 머리·대화·추천 질문·입력창은 그대로, 말풍선·칩·입력창 모양만 바꿈)
4. **내 현황**: 주황 숫자 카드 4칸(지금의 KPI 4개) + 공정 카드 4칸(번호·이름·이해도·진행 막대·시도 횟수)
5. **복습**: 다시 볼 개념 · 내 오개념을 폴더 탭 대신 **두 칸으로 나란히** 둔다. 오개념 줄은 `+`로 펼쳐 설명을 본다(`<details>`). 다시 볼 개념 줄은 펼칠 설명이 없어 한 줄(개념 · 공정 · 날짜 · 판정)로 둔다. 오개념 내용은 지금처럼 본인 화면에만 보인다.
6. **평가 시험 띠**(맨 아래 검정 띠): 큰 글씨 PROVE & PASS. + 주황 버튼 `평가 시험 응시 →`. 튜터 위의 '평가 시험 응시 ↗' 링크는 헤더와 이 띠에 있으므로 뺀다.

좁은 화면(1100px 이하)에서는 학습 영역과 복습 두 칸을 세로로 쌓는다. 600px 이하 헤더 규칙은 지금 것을 유지한다.

### UI 편집기로 다듬은 배치 (2026-10-15)

UI 편집기(`frontend/login_ui/ui-editor.html`)에서 1465px 폭으로 편집한 결과를 레이아웃 규칙으로 옮겼다(위치 px를 그대로 붙이지 않음).

- 헤더: 가로 여백을 0으로 해 로고·버튼을 본문 왼쪽·오른쪽 끝선에 맞춘다.
- 제목띠: 주황 패널을 348px로 줄여 오른쪽 끝에 붙인다. 불러오기 오류는 따로 카드를 두지 않고 '불러온 시각' 옆에 한 줄(`dg-alert`)로 보인다. 본문 위 여백 36 → 28px.
- 학습 영역: 튜터 칸 380 → 348px, 간격 24px. 튜터 위 'AI TUTOR' 줄을 빼 튜터 위쪽을 모듈 탭 줄에 맞춘다. 튜터 높이는 모듈과 같게 둔다(#142, 편집에서는 낮췄지만 규칙 유지로 정함).
- 4번 내 현황과 5번 복습을 **한 줄(`dg-split`, 3:2)**로: 왼쪽에 주황 숫자 카드 4칸(높이 200px)과 그 아래 공정 카드 4칸, 오른쪽에 다시 볼 개념·내 오개념을 위아래로. 1100px 이하에서는 위아래로, 600px 이하에서는 카드 2칸씩.
- 평가 시험 띠: 버튼을 크게(높이 80px, 최소 너비 360px, 글자 20px), 띠 높이 최소 188px, 버튼 오른쪽 여백 108px.

### 학습 모듈 탭·판과 선 맞춤 (2026-10-15)

- 학습 모듈 판(2D 모듈 `process-2d.js`의 `.root`, 설계도·필기 `.dg-mframe`)은 **탭이 붙는 왼쪽 위만 각지고 나머지 세 모서리가 둥근 판**(18px)이다. 판 모양은 뒤쪽 층(`::before` 선, `::after` 바탕)에만 그려 설비 미리보기 창이 판 밖으로 나가도 잘리지 않는다. 판 안의 공정 탭·설비 목록·단계 설명·썸네일·그림도 둥근 모서리이고, 단계 번호·화살표·재생 버튼은 원이다. 2D 모듈 글꼴도 Montserrat(한글 Pretendard).
- 판 바탕은 살짝 따뜻한 회색 `--module-bg`(다크 `#24211e`, 라이트 `#f0ece6`), 설비 목록 바탕 `--module-panel`.
- 탭(작동 단계 | 설계도·필기, `.dg-ftabs`, 높이 `--mtab-h` 40px)은 브라우저 탭처럼 고른 탭이 판과 같은 바탕으로 이어지고 위에 주황 줄이 있다.
- 선 맞춤(1100px 넘는 화면, 작동 단계 탭): 튜터 위쪽 = 판 위쪽, 튜터 머리 아래 선 = 그림 위쪽 = 설비 목록 위쪽, 추천 질문 위쪽 = 단계 설명 위쪽, 입력창 아래쪽 = 단계 설명 아래쪽, 튜터 아래쪽 = 판 아래쪽. 단계 설명 높이가 단계마다 달라 `alignTutor()`가 2D 모듈 안을 재서 `body`의 CSS 변수(`--tutor-head-h`, `--tutor-foot-h`, `--tutor-foot-pb`)로 넣는다.

### 반투명 판·탭 이동·등장 움직임 (2026-10-15)

- 배경: 다크는 어두운 바탕에 따뜻한 주황 빛 번짐과 옅은 격자, 라이트는 미색 바탕에 갈색·핑크 회색 빛. 판은 외곽선 없이 반투명(`--glass`, `--blur`)이고, 라이트 모드의 진한 판(튜터·평가 시험 띠)은 갈색·핑크 회색 그라데이션이다.
- 주황 버튼: 평소 주황 테두리 + 옅은 주황, 마우스를 올리면 주황으로 채운다. 고른 탭의 주황 줄, 판 외곽선, 구역 나눔 선과 `+` 표시는 지웠다.
- 내 현황·복습(다시 볼 개념)·내 오개념은 아래 구역 대신 학습 모듈 탭(작동 단계 | 설계도·필기 | 내 현황 | 복습 | 내 오개념)에서 연다. 탭 판은 최소 높이 640px이고 튜터는 판 높이를 따른다.
- 지금 공정: 큰 숫자 대신 이해도 도넛. 들어올 때 한 바퀴 돌며 수치만큼 채우고 가운데 숫자는 0부터 센다.
- 등장: 헤더 → 제목 → 지금 공정 → 학습 모듈 → 튜터 → 평가 시험 띠 순서로 창이 뜨듯 열린다(`.dg-pop`, 지연 `--d`). 탭을 바꾸면 그 판이 다시 열린다. 움직임이 끝나면 튜터 선 맞춤을 다시 잰다. 움직임 줄이기 설정이면 끈다.
- 여백: 본문 폭 1320px, 양옆 최소 48px, 구역 사이 64px.

### 군더더기 정리 (2026-10-15)

- 헤더: 로고 옆 `TRAINEE`를 `LEARN & ASK`로 바꾸고 데이터 출처 배지(DB 데이터)를 뺐다. 불러오기 오류는 제목띠의 오류 한 줄로 보인다.
- 제목띠: 큰 제목을 `FORGE THE BASICS.`로 바꾸고 설명 줄(이름·사번·안내 문장)을 뺐다. 학습 모듈 탭은 제목띠 바로 아래에 붙인다(간격 28px).
- 내 현황 탭을 뺐다(지금 공정 도넛과 겹침). 탭은 작동 단계 | 설계도·필기 | 복습 | 내 오개념.
- 맨 아래 평가 시험 띠를 뺐다(헤더 [평가 시험] 버튼과 겹침).

### 2D 모듈 배치 다듬기 (2026-10-15)

- 헤더와 제목띠 사이 여백을 28px로 줄였다. 제목 묶음은 지금 공정 판 위쪽에 맞추고, 학습 모듈 탭은 지금 공정 판 바로 아래(8px)에 붙였다.
- 공정 토글(제선·제강·연주·열간압연)을 모듈 맨 위 줄에서 오른쪽 설비 목록 위로 옮겼다. 목록과 같은 폭(288px)을 네 칸으로 고르게 나누고, 토글 34px + 간격 6px로 설비 목록 위쪽이 그림 위쪽에 맞는다.
- 설비 목록 머리 오른쪽의 설비 수 대신 `다음 공정 →` 버튼을 두고, 마지막 공정(열간압연)에서는 `← 이전 공정`이 된다. 목록 아래 다음 공정 줄은 뺐다.
- 단계 설명이 남은 높이를 채워 아래선이 설비 목록 아래선과 같다. 튜터 입력창 아래선도 그 선에 맞는다.
- 그림이 위로 올라가 튜터 머리 아래선(= 그림 위쪽)이 58px이 되어 포석호 칸을 48×54로 줄였다.
- 헤더는 스크롤을 따라오지 않고 페이지 맨 위에 둔다(sticky 해제).

### UI 검증 반영 (2026-10-15)

`AI_UIUX_검증.md`·디자인 피드백 정리·가독성 원리 노트를 기준으로 1440px·375px, 다크·라이트에서 재고 고쳤다.

- 대비: 라이트 튜터 판은 그라데이션 대신 단색(`#c9bab3`)으로 두고 글자색(주황·빨강·보조)을 진하게 했다. 라이트 주황 글자 `#9a4512`, 2D 모듈 라이트 강조색도 같은 값. 측정한 모든 글자가 4.5:1 이상이다(배경 빛 번짐은 빼고 계산한 근사값).
