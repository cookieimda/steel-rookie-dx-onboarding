작성 2026-10-10 · 상태: **검수 전 초안**. 아래 숫자는 교육 화면(3D 설비 단계 카드)과 튜터 답변에 넣을 후보입니다.
현장 경험자 검수를 거친 숫자만 `content/materials/{섹션}/section.md`(교육 내용의 단일 기준)에 옮깁니다.

## 검수하는 방법
- 각 줄 끝 **검수** 칸에 표시해 주세요: `맞음` / `수정: ○○` / `모름`
- 회사·설비마다 값이 다른 항목은 "우리 현장 기준 값"을 적어 주시면 그 값을 씁니다.
- 공정마다 끝에 있는 **현장 질문**은 공개 자료로 확인하지 못한 것들입니다.

**신뢰도 기준**
| 표시 | 뜻 |
|---|---|
| 높음 | 회사 공식(포스코·현대제철 뉴스룸·사업 자료), 정부(US EPA), 국제 협회(worldsteel), 설비·크레인 제조사 공식 자료, 제철사 기술보고서 |
| 중간 | 업계 기술 해설(ispatguru), 업계지·지역 언론, 대학 강의(NPTEL), 특허, 검색 요약으로만 본 학회 자료 |
| 낮음 | 판매사 카탈로그, 원문을 못 연 자료 |
| 계산 | 부피 × 밀도(철 약 7.8t/m³) 등으로 직접 계산 |

구글 AI 요약·블로그는 근거로 쓰지 않았습니다.

## 0. 크레인 톤수 피드백 판정
피드백(구글 AI 요약 인용)의 크레인 톤수를 1차 자료와 계산으로 확인했습니다.

| 피드백 내용 | 판정 | 근거 | 화면에 쓸 표현(안) | 검수 |
|---|---|---|---|---|
| 연주 정정 크레인 45~50톤급, 슬래브 약 30톤을 집게(Tong)로 이송 | **개연성 있음, 1차 근거 없음** | 슬래브 0.25×1.5×10m×7.8 = 29t, 집게 무게를 더하면 40t대 필요(계산). 실제 사례: 집게 크레인 최대 70t, 900℃ 슬래브 1~3장 동시 취급([Konecranes, Mittal 폴란드](https://konecranes.com/press-releases/kci-konecranes-receives-major-order-for-mittal-steel-in-poland)) | "슬래브 한 장 약 30톤 → 수십 톤급(예: 40~70t) 집게 크레인이 1~3장씩" | |
| 고온 슬래브 야드 크레인 100~150톤급 | **대체로 맞음** | 슬래브 크레인 표준 용량 120t([Konecranes](https://konecranes.com/en-us/industries/metals-production/equipment-for-lifting-metals/slab-and-billet-handling-cranes)) | "야드 크레인 약 100톤급" | |
| 제강 래들 크레인 200~300톤 이상 | **하한이 낮을 가능성 큼** | 크레인은 용강 + 래들 자체 무게를 듦. 용강 250t 래들의 빈 무게 약 115t(철피 60 + 내화물 55, [China Steel 기술보고 No.35](https://www.csc.com.tw/csc/ts/ena/pdf/no35/pages/2-Analysis%20of%20Temperature%20Dropping%20of%20Molten%20Steel%20in%20Ladle%20for%20Steelmaking.pdf)). 같은 비율이면 용강 300t 래들은 합계 약 440t → **450t급 이상**(계산). 제조사 래들 크레인 범위: 트롤리 2대 100~540t([Konecranes](https://www.konecranes.com/industries/metals-production/equipment-for-lifting-metals/double-girder-ladle-handling-cranes)) | "용강 300톤이 든 래들(전체 약 440톤)을 450톤급 크레인이" | |

- 포스코 뉴스룸 '지능형 자동 크레인'(2026-01-13) 기사에는 톤수가 없어 근거로 쓰지 않았습니다.
- 지금 화면의 "천장 크레인이 300톤 래들을 들어"는 300톤을 **용강 무게**로 바꿔 써야 합니다(제강 표 참고).
