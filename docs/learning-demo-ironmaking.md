# 제선 학습 튜터 시연 순서

제선 공정만 시연할 때 학습 튜터(AI 튜터의 **학습** 탭)를 보여 주는 순서다. 아래 질문은 모두 `npm run eval:learning`에서 실제 Gemini로 확인한 것이다(2026-10-06, `gemini-3.5-flash-lite`). 답 문장은 매번 조금씩 다르다.

## 시연 전 (10분)

1. `.env`에 `GEMINI_API_KEY`, `JWT_SECRET`을 넣는다. `JWT_SECRET`이 없으면 서버를 다시 켤 때마다 로그인이 풀린다. `GEMINI_MODEL`은 평가한 모델(`gemini-3.5-flash-lite`)로 둔다.
2. `npm run eval:learning -- --follow-up`을 돌려 전체 통과가 50개 이상인지 본다(약 5분, Gemini 호출 약 100회). 과부하(503)·연결 오류가 이어지면 그날은 모델 상태가 나쁜 것이다. [Google AI Studio 상태](https://aistudio.google.com/status)를 확인한다.
3. `npm start` → `/login`에서 시연 계정(`trainee01` 등)으로 로그인 → `http://localhost:3000/?p=ironmaking&tutor=1`.
4. 시연 계정의 이전 대화가 보이면 새 탭에서 연다(채팅 유지 PR 병합 후에는 대화가 탭마다 이어진다).

## 시연 순서

| 순서 | 화면 | 하는 것 | 보여 줄 것 |
|---|---|---|---|
| 1 | 제선, 설비 선택 없음 | 추천 질문 **"제선 공정 순서를 보여 줘"** | 소재 흐름 애니메이션 재생, 근거 출처 표시 |
| 2 | 제선 | 직접 입력 **"고로는 무슨 일을 해?"** | 카메라가 고로로 이동하고 고로 선택(설비 패널), 출처 링크 |
| 3 | 고로 선택 상태 | 추천 질문 **"고로에 열풍을 왜 불어넣어?"** | 추천 질문이 고로에 맞게 바뀐 것, 약 1,200℃ 열풍 설명 |
| 4 | 제선 | 직접 입력 **"토페도카는 뭘 옮겨?"** | 토페도카로 이동, 약 300톤·약 1,500℃ 쇳물, 출처 '지구상에서 제일 뜨거운 기차' |
| 5 | 토페도카 선택 | 답 아래 **'생각해 보기'** 누르기 | 꼬리 질문도 근거 있는 답 |
| 6 | 제선 | 직접 입력 **"코크스는 불순물 없애려고 넣는 거죠?"** | 튜터가 첫 문장에서 바로잡아 줌("불순물을 없애는 것이 주된 역할은 아니에요"). 이 오개념은 기록되어 마이페이지에 '대화 중 감지됨'으로 보인다 |
| 7 | 제선 | 직접 입력 **"쇳물은 다음에 어느 공정으로 가?"** | 제강 화면으로 이동 |
| 8 | 아무 화면 | **새로고침** | 채팅이 그대로 남아 있음(학습 튜터 채팅 유지 PR 병합 후) |
| 9 | 제선 | 직접 입력 **"고로 밸브는 어떻게 열어요?"** | 튜터를 부르지 않고 안전 안내 문장. 작업 절차는 현장 지침으로 안내 |

시간이 남으면: "고로는 그렇게 뜨거운데 왜 안 녹아?"(내화물), "코크스는 몇 도에서 만들어?"(1,300℃ 건류), "출선구는 뭐야?"(출선구로 이동).

## 피할 질문

- **제강·연주·열간압연 내용**: 이제 공정마다 근거 메모가 있어 답은 하지만, 시연은 제선만 준비했다(추천 질문·대본은 제선뿐). 물어보면 답하되 시연 흐름으로 쓰지 않는다.
- **출처마다 숫자가 다른 것**: 코크스 건류 온도(1,300℃ / 1,000~1,300℃)처럼 출처가 둘이면 튜터가 둘 중 하나나 범위로 답한다. 정확한 숫자를 묻는 시연은 피한다.
- **비용·연봉·생산량 같은 수치**: 자료에 없으면 "확인되지 않습니다"로 답한다(지어내지 않는 것을 보여 주고 싶을 때만 쓴다).

## 문제가 생기면

| 증상 | 원인 | 할 것 |
|---|---|---|
| "답변을 받지 못했어요" | Gemini 과부하(503)·연결 끊김. 서버가 1초·2초 뒤 2번 다시 부른 뒤에도 실패 | **다시 시도**를 누른다. 이어지면 잠시 뒤 다시 하거나 추천 질문으로 넘어간다 |
| 답이 20초 넘게 걸림 | Gemini 응답 지연 | 기다리는 동안 3D 화면(단면·흐름 보기)을 설명한다 |
| 오늘 쓸 수 있는 튜터 호출을 다 썼다는 안내 | 사용자별 하루 한도(`LLM_DAILY_LIMIT`, 기본 150회) | 다른 시연 계정으로 로그인한다 |
| 로그인이 풀림 | `JWT_SECRET` 없이 서버를 다시 켬 | 다시 로그인한다. 다음부터는 `.env`에 넣는다 |
